# arubox

一个常驻在 Windows 通知区域的轻量工具箱：启动器、截图、翻译和桌面整理。界面由 arubox 自己绘制，不带浏览器内核，也不占用显卡，内存占用低。

每个功能都可以在仪表盘里单独开关，关掉的功能不占内存，快捷键也不生效。

## 功能

- **启动器**（默认 Alt+Shift+Space）：查找并打开应用、文件和文件夹，中文名字可以用拼音首字母找；直接计算算式、换算汇率、查看各地时间、翻译文字；用关键词搜索网站，如「gg 天气」；以 `!` 开头在终端里运行命令。
- **文件搜索**：像 Everything 一样快，覆盖所有硬盘，支持它的搜索写法，如 `*.pdf`、`ext:docx`。第一次开启时需要管理员授权，安装一个小的后台服务。
- **截图**：框选区域或点选窗口，画矩形、椭圆、箭头、画笔、文字和马赛克，然后复制、保存或贴在屏幕上，也能识别或翻译图里的文字。开着 HDR 时颜色也和屏幕上一样。
- **翻译**：输入翻译、划词翻译和截图翻译都在同一个小浮窗里完成，可选 Google 翻译、Edge 翻译或 DeepL，能朗读原文和译文。文字识别可以换成能下载的 PP-OCRv6，不用装系统语言包就能认中文、英文和日文。
- **桌面整理**：在桌面空白处拖出一个框就能建盒子，把图标归进去；也可以建文件夹入口，在桌面上直接浏览某个文件夹。文件仍在桌面文件夹里，关掉这个功能后图标回到原来的位置。
- **自动更新**：自动检查新版本，确认后下载、安装并重启。

## 安装

从 [Releases](https://github.com/shirumesu/arubox/releases) 下载对应架构的 exe，直接运行即可。支持 Windows 10 / 11，x64 和 Arm。

## 从源码构建

需要 Go（版本见 `go.mod`）和 [Task](https://taskfile.dev)：

```bash
task build
```

生成的程序在 `bin/arubox.exe`。`task run` 构建并运行开发版，`task lint` 检查代码。
